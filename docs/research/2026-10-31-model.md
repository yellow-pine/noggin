# Digital model research (2026-10-31)

## Fusion API for the model

Base URL for all reference links: `https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/` (abbreviated `REF/` below). Forum claims are marked **[forum]**; Autodesk forum pages return 403 to fetch tools, so those are from search excerpts only.

### 1. STEP import

- `importManager.createSTEPImportOptions(filename)` -> `STEPImportOptions` or null. "Creation of the STEPImportOptions object does not perform the import." One signature for assembly and single-body STEP; there is no separate single-body variant. REF/core_ImportManager_createSTEPImportOptions.htm
- `STEPImportOptions.isViewFit`: "defaults to true, which will cause a change in the current view"; set False to leave the camera. REF/core_STEPImportOptions.htm
- `importManager.importToTarget(options, targetComponent)` -> bool. Cannot be used inside Command-related events. REF/core_ImportManager_importToTarget.htm
- `importManager.importToTarget2(options, target)` -> `ObjectCollection` of created objects, null on failure (Sept 2017). This is the documented way to get the created occurrence(s); the collection contents for STEP are not spelled out in the reference. REF/core_ImportManager_importToTarget2.htm
- Sample (`stpOptions.isViewFit = False; importManager.importToTarget(stpOptions, rootComp)`): REF/ImportManager_Sample.htm
- **[forum]** STEP files import as components; a multi-component STEP yields one component with one body each; a script finds the new occurrence by comparing `occurrences.count` before/after and taking the last one. https://forums.autodesk.com/t5/fusion-360-api-and-scripts/can-t-get-brepbodies-from-imported-step-file/td-p/11065155 , https://forums.autodesk.com/t5/fusion-support-forum/imported-assembly-file-structure-has-bodies-vs-components/m-p/12726262
- Renaming: `Occurrence.name` is read-only ("This is a read only property"). REF/fusion_Occurrence_name.htm. `Component.name` is read/write; the occurrence name is derived from it (`"OccurrenceName:1"`). REF/fusion_Component_name.htm , REF/fusion_Occurrence.htm. So rename via `occ.component.name = ...`, which renames every occurrence of that component **[forum]** https://forums.autodesk.com/t5/fusion-api-and-scripts-forum/is-there-any-api-to-rename-occurrence-object/m-p/10605021

### 2. Mesh -> BRep

- `MeshConvertFeatures.createInput(inputBodies: MeshBody[])` -> `MeshConvertFeatureInput`; preview API, introduced July 2025, "you should never deliver any programs that use any preview capabilities". REF/MeshConvertFeatures_createInput.htm
- `MeshConvertFeatureInput` properties: `inputBodies`, `meshConvertMethodType` (default Faceted), `meshConvertOperationType` (default parametric), `meshConvertResolutionType` (organic only, default by accuracy), `meshConvertAccuracyType` (organic), `numberOfFaces` (by-facet-number only), `isPreprocessHoles` (organic), `targetBaseFeature`. REF/fusion_MeshConvertFeatureInput.htm
- `MeshConvertMethodTypes`: `FacetedMeshConvertMethodType`=0 (each mesh face -> one BRep face), `PrismaticMeshConvertMethodType`=1 (face groups merged into prismatic faces), `OrganicMeshConvertMethodType`=2 (needs Product Design Extension). REF/fusion_MeshConvertMethodTypes.htm
- `MeshConvertOperationTypes`: `ParametricFeatureMeshConvertOperationType`=0, `BaseFeatureMeshConvertOperationType`=1. REF/fusion_MeshConvertOperationTypes.htm
- `MeshConvertFeatures.add(input)` -> `MeshConvertFeature` (null for non-parametric). `MeshConvertFeature.bodies` "Returns the bodies that were modified or created by this feature"; `inputBodies` returns the meshes. Reference does not say whether the source MeshBody survives (UI Convert consumes it; unverified for API). REF/fusion_MeshConvertFeatures_add.htm , REF/fusion_MeshConvertFeature.htm
- Performance **[forum]**: faceted convert makes one BRep face per triangle, slow above ~10k faces; decimate first, or use a base feature (direct) to avoid timeline recompute. https://forums.autodesk.com/t5/fusion-support-forum/converting-mesh-to-brep-painful/td-p/8585730
- `TemporaryBRepManager.createFromFile(filename)` reads "SMT, SMB, SAT, or SAB" only, returns `BRepBodies`; not STL/OBJ/STEP. REF/fusion_TemporaryBRepManager_createFromFile.htm

### 3. Joints

- `joints.createInput(geometryOrOriginOne, geometryOrOriginTwo)` where each is a `JointGeometry` (static creators) or `JointOrigin` (from `JointOrigins`); then `joints.add(input)`. REF/fusion_Joints_createInput.htm
- `JointGeometry.createByPoint(point)` (ConstructionPoint, SketchPoint, BRepVertex). REF/fusion_JointGeometry_createByPoint.htm
- `createByPlanarFace(face, edge, keyPointType)`: edge may be None only with `CenterKeyPoint`. REF/fusion_JointGeometry_createByPlanarFace.htm
- `createByNonPlanarFace(face, keyPointType)`: cylinder/cone accept Start/Middle/End; sphere/torus need Center. REF/fusion_JointGeometry_createByNonPlanarFace.htm
- `createByCurve(curve, keyPointType)`: BRepEdge or SketchCurve; circles need `CenterKeyPoint`. REF/fusion_JointGeometry_createByCurve.htm
- `jointOrigins.createInput(geometry)` -> `JointOriginInput`; `jointOrigins.add(input)` -> `JointOrigin`. REF/fusion_JointOrigins_createInput.htm , REF/fusion_JointOrigins_add.htm
- `JointOriginInput`: `geometry`, `offsetX/Y/Z` (ValueInput; real = cm), `angle` (real = rad), `isFlipped`, `xAxisEntity`, `zAxisEntity` (default null = inferred). REF/fusion_JointOriginInput.htm
- `JointOrigin`: `primaryAxisVector` is the triad Z, `secondaryAxisVector` X, `thirdAxisVector` Y; `transform` gives origin + axes as Matrix3D. REF/fusion_JointOrigin.htm
- Arbitrary point with orientation: no API takes a raw Point3D; use a ConstructionPoint/SketchPoint with `createByPoint`, then `xAxisEntity`/`zAxisEntity` + offsets/angle on the JointOriginInput (inferred from the reference above; not stated as a recipe).
- `jointInput.setAsRevoluteJointMotion(rotationAxis, customRotationAxisEntity=None)` -> bool; custom entity required iff `CustomJointDirection`. REF/fusion_JointInput_setAsRevoluteJointMotion.htm
- `JointDirections`: `XAxisJointDirection`=0, `YAxisJointDirection`=1, `ZAxisJointDirection`=2, `CustomJointDirection`=3. REF/fusion_JointDirections.htm
- `JointInput.angle` / `offset` (ValueInput; real = rad / cm), `isFlipped` (third axes facing vs opposed). REF/fusion_JointInput.htm
- `RevoluteJointMotion`: `rotationValue` "is in radians", setting it "is equivalent to using the Drive Joints command"; `rotationLimits` -> `JointLimits`; `customRotationAxisEntity` (linear edge, sketch line, planar or cylindrical face). REF/fusion_RevoluteJointMotion.htm
- `JointLimits`: `minimumValue`, `maximumValue`, `restValue` (cm or rad), `isMinimumValueEnabled`, `isMaximumValueEnabled`, `isRestValueEnabled`. REF/fusion_JointLimits.htm. Sample: REF/RevoluteJointMotionSample_Sample.htm
- `Joint.isLocked`, `isSuppressed` get/set; `healthState` + `errorOrWarningMessage`. REF/fusion_Joint.htm , REF/JointSample_Sample.htm
- `rigidGroups.add(occurrences: ObjectCollection, includeChildren: bool)` -> `RigidGroup`. REF/fusion_RigidGroups_add.htm
- `asBuiltJoints.createInput(occurrenceOne, occurrenceTwo, geometry)`; geometry null for rigid; then `.add`. REF/fusion_AsBuiltJoints_createInput.htm

### 4. Motion links and loop closure

- `motionLinks.createInput(jointOne, jointTwo=None)` -> `MotionLinkInput`; `motionLinks.add(input)` -> `MotionLink`. Rigid joints never valid; introduced November 2025. REF/fusion_MotionLinks_createInput.htm , REF/fusion_MotionLinks_add.htm
- `MotionLinkInput`: `jointOne`, `jointTwo`, `valueOne`, `valueTwo` (real = cm/rad, strings may carry units), `isReversed`. Ratio = valueOne : valueTwo. REF/fusion_MotionLinkInput.htm
- Four-bar closure: reference is silent. **[forum]** closing a loop with a fourth revolute fails when axes are not exactly coplanar/parallel; the usual fix is a cylindrical joint at one pivot (frees the extra DOF), and "Fusion's joint system is not designed to solve" redundant constraints. https://forums.autodesk.com/t5/fusion-design-validate-document/trouble-using-joint-revolve-on-a-4-bar-linkage/m-p/13311234 , https://forums.autodesk.com/t5/fusion-design-validate-document/four-bar-linkage/td-p/6764145 , https://forums.autodesk.com/t5/fusion-support-forum/how-to-resolve-overconstrains-on-energy-chain-design/td-p/13658878
- Practical plan for the model: three revolutes + one cylindrical (or one revolute left out and the link held by a rigid group), drive with `rotationValue`, and check `joint.healthState` after each add.

### 5. Interference and measurement

- `design.createInterferenceInput(entities: ObjectCollection)` of BRepBody/Occurrence; "All entities must be in the context of the root component". REF/fusion_Design_createInterferenceInput.htm
- `design.analyzeInterference(input)` -> `InterferenceResults` (`count`, `item(i)`, `createBodies(allInterferenceBodies)`; createBodies "is not supported in parametric modeling"). REF/fusion_Design_analyzeInterference.htm , REF/fusion_InterferenceResults.htm , REF/fusion_InterferenceResults_createBodies.htm
- `InterferenceResult`: `entityOne`, `entityTwo`, `interferenceBody` (transient BRepBody; use its `.volume`, cm^3), `isCreateBody`. There is no `.volume` on the result itself. REF/fusion_InterferenceResult.htm
- `measureManager.measureMinimumDistance(a, b)` accepts Occurrence, BRepBody/Face/Edge/Vertex, construction geometry, sketch entities, Plane, Point3D. REF/core_MeasureManager_measureMinimumDistance.htm
- `MeasureResults.value` "will be in centimeters" for distance (radians for angle); `positionOne`/`positionTwo` are the closest points. REF/core_MeasureResults.htm

### 6. Referencing saved designs and versioning

- `occurrences.addByInsert(dataFile: DataFile, transform: Matrix3D, isReferencedComponent: bool)` -> Occurrence; fails if the DataFile is from another project and `isReferencedComponent` is True; first arg must be a saved file's DataFile, not a Document. REF/fusion_Occurrences_addByInsert.htm
- `Occurrence.isReferencedComponent` reports an x-ref. REF/fusion_Occurrence.htm
- Joints to x-ref geometry **[forum]**: geometry taken straight from the referenced component's sketch/body fails in `JointGeometry`; wrap it with `entity.createForAssemblyContext(occurrence)` first, or insert with `isReferencedComponent=False`. https://forums.autodesk.com/t5/fusion-api-and-scripts-forum/problem-creating-joint-for-imported-component-if-referenced/m-p/10625014 , https://forums.autodesk.com/t5/fusion-api-and-scripts/rigid-joint-between-an-external-inserted-component-and-a-sketch/td-p/12941821
- `document.saveAs(name, dataFolder, description, tag)` -> bool; required for a never-saved document. `document.save(description)` -> bool; "saves a version". Neither works inside Command events. REF/core_Document_saveAs.htm , REF/core_Document_save.htm

### 7. Units and transforms

- Design API units: length cm, angle radians, mass kg, regardless of document display units; convert with `UnitsManager` only at the UI boundary. REF/Units_UM.htm
- `matrix.setToRotation(angle_rad, axis: Vector3D, origin: Point3D)` -> bool. REF/core_Matrix3D_setToRotation.htm
- `matrix.setToAlignCoordinateSystems(fromOrigin, fromX, fromY, fromZ, toOrigin, toX, toY, toZ)` (note plural name) maps the from-CS onto the to-CS. REF/core_Matrix3D_setToAlignCoordinateSystems.htm
- `Occurrence.transform` is retired ("there are cases where it returns the incorrect results"); use `transform2`. REF/fusion_Occurrence_transform2.htm
- `Occurrence.isGrounded` "Gets and sets whether this occurrence is pinned or not"; `isGroundToParent` also exists. REF/fusion_Occurrence_isGrounded.htm

## Verified live in Fusion 2706.1.17 (2026-10-31, via the MCP `script` tool)

- `importManager.importToTarget2(stepOptions, root)` returns one `Occurrence` for the servo STEP; rename
  with `occ.component.name = ...` (the occurrence shows as `name:1`).
- `ConstructionPoints.add` with `setByPoint` raises "Environment is not supported" in a parametric design.
  Joint origins instead go on a sketch point (`sketch.sketchPoints.add`) with `JointOriginInput.offsetZ`
  for the out-of-plane coordinate, then `jointOrigin.createForAssemblyContext(occ)` in `joints.createInput`.
- Revolute joint with `rotationLimits` (radians) and `rotationValue` drive works; the driven occurrence's
  `transform2` reflects the motion.
- `measureMinimumDistance(bodyA, bodyB).value` is cm and reads 0 when bodies overlap (positions then zeroed);
  `analyzeInterference` returns results whose `interferenceBody.volume` is cm^3.
- Mesh -> BRep: faceted convert works in a parametric design only (3.3 s per 36k-face part, 74 s for 275k);
  in a direct design `MeshConvertFeatures.add` returns None, and organic conversion is not licensed.
- Full-resolution parts are fine for conversion; 70 distance measurements against 36k-face bodies hung
  Fusion, so checks sweep decimated copies (see face/decimate.py).
